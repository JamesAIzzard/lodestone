# Lodestone

Local semantic search over your files via MCP.

Lodestone can also mirror selected email accounts into read-only `Mail: …` silos. Messages are stored locally as searchable Markdown without downloading attachments or changing the server; see the [email mirror documentation](docs/email-mirror/00-overview.md) for the design and setup details.

## Development

```bash
npm install
npm start
```
